# SafeHer AI 🚨

SafeHer AI is an AI-powered women safety system designed to work even when the user cannot press a button.

## 🔍 Problem
Most women safety apps depend on manual triggers, which often fail during real emergencies.

## 💡 Solution
SafeHer AI uses AI & ML to detect emergencies automatically:
- Voice AI to detect distress words ("Help", "Bachao")
- Motion AI to identify struggle via phone-shake patterns
- ML-based real-time risk scoring (0–100%)
- Automatic 120dB siren alerts
- Live GPS tracking to emergency contacts
- Runs silently in the background

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- AI Logic: Audio & Motion Pattern Detection
